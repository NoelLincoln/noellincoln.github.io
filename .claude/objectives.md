# Objectives

## Product Goals

- Migrate portfolio from static HTML/CSS/JS to Next.js + Tailwind CSS + shadcn/ui + Framer Motion.
- Ship the UI first with static data — no backend dependency in Phase 1.
- Add Django + PostgreSQL backend in a later phase to power projects and contact form.
- Preserve and improve SEO performance (metadata, sitemap, structured data).

## Learning Goals

- Build practical Next.js App Router skills (components, metadata, routing, Tailwind).
- Build practical Django skills (models, admin, REST APIs) — in a later phase.
- Improve end-to-end full-stack architecture and delivery workflow.

## MVP Definition (Phase 1–3)

- Next.js app with all portfolio sections: Hero, Projects, About, Contact.
- Static project data from `data/projects.ts` — no API calls yet.
- Dark/light mode carried over from current site.
- Deployed on Vercel.

## Non-Goals (Phase 1–3)

- No Django backend yet.
- No SSR or dynamic data fetching.
- No blog — may be added post-Django integration.
- No custom CMS UI.
